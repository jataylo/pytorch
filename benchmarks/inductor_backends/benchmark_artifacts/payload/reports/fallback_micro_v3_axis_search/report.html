Fallback kernel probes

Representative expressions from CoaT, ConvNeXt, Qwen and CAiT, plus a three-axis pointwise expression. These are warm-input CUDA-graph kernel measurements, including backward-style arithmetic. They are not full-model training results.

Times are microseconds; ratio = Triton / FlyDSL, so above one favors FlyDSL. Each value is the median of seven replay windows after three settling windows and 30 warmup calls. The same inputs and physical GPU were used for all variants. All 20 variants passed their numerical checks and exercised the intended FlyDSL paths. GEMM/conv lowering is ATen; optional Triton-versus-FlyDSL runtime selection is off.

Autotune 0 disables the expanded SIMD/pointwise search; limited native reduction selection remains. Autotune 1 enables eligible searches. The mixed-order path has no expanded launch search, despite its enabled flag. CAiT and pointwise are described as near parity because native Triton timings varied between validation windows. Variable samples are flagged rather than used to claim a winner.
